# 乗換駅グループ一覧（確認用）

> 判定結果は `data/transfer-group-overrides.json` に反映済みです（詳細は README「乗換グループの調整」）。

`public/data/network.json`（Mini Tokyo 3D由来）の乗換グループです。同じグループに入っている駅同士は、乗換300秒（5分）で乗り換えられるものとして扱われます。

**記入方法**: 各項目の「判定」欄に、以下のいずれかを書いてください（空欄は「OK」扱い）。

| 記入 | 意味 | 使える章 |
|---|---|---|
| `OK` | このままでよい | 全章 |
| `分割: 駅名A / 駅名B …` | 書いた駅名ごとに別の乗換駅に分ける（別グループ間は乗換不可） | 第1章・第2章 |
| `統合` | 2つのグループを1つの乗換駅にまとめる | 第3章 |
| `除外` | 判定があいまいでプレイヤーに分かりづらいので、この乗換駅（グループ内の全駅）を出題の出発駅・到着駅に使わない | 全章（第3章では両グループが対象） |

- グループ総数: 1936（うち複数駅: 351）
- 第1章 駅名が異なる駅を含むグループ: 66件（最大駅間距離の大きい順）
- 第2章 同じ駅名だけのグループ: 285件
